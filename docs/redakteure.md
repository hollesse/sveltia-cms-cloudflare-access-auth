# Anleitung für Redakteurinnen und Redakteure

Sie brauchen **kein GitHub-Konto** und **kein Passwort** — nur Ihre
E-Mail-Adresse.

## So melden Sie sich an

1. Öffnen Sie die Redaktionsseite Ihrer Website (z. B. `…/admin/`).
2. Klicken Sie auf den Anmelde-Button. Es öffnet sich ein kleines Fenster.
3. Wählen Sie **„Mit E-Mail-Code anmelden"** (falls eine Auswahl erscheint).
4. Geben Sie Ihre E-Mail-Adresse ein. Sie bekommen sofort eine E-Mail mit
   einem Zahlencode. Kein Code angekommen? Prüfen Sie den Spam-Ordner —
   und ob Ihre Adresse für die Website freigeschaltet ist (im Zweifel beim
   Betreiber nachfragen).
5. Code eintippen — fertig, Sie sind angemeldet und können schreiben.

Die Anmeldung hält etwa eine Woche. Danach fragt das System einfach einmal
neu nach einem Code.

**Falls „Mit GitHub anmelden" angeboten wird** (nur, wenn der Betreiber das
eingerichtet hat): Nach dem Klick öffnet sich ein zweites Fenster für die
eigentliche GitHub-Anmeldung — bitte Pop-ups für diese Seite erlauben, falls
der Browser das zweite Fenster blockiert.

## Wenn beim Speichern ein Fehler erscheint

Gelegentlich erneuert das System im Hintergrund Ihre Anmeldung. Falls genau
dann eine Meldung wie **„Bad credentials"** oder „Speichern fehlgeschlagen"
auftaucht: **Ihr Text ist nicht verloren.** So geht es weiter:

1. Laden Sie die Seite neu (Taste **F5** bzw. ⌘R am Mac).
2. Melden Sie sich erneut an — das ist meist nur ein Klick, ohne neuen
   E-Mail-Code.
3. Öffnen Sie den Bereich, in dem Sie geschrieben haben, und klicken Sie auf
   **„Neu"** bzw. den Eintrag, an dem Sie gearbeitet haben: Das CMS bietet
   Ihnen an, den **gesicherten Entwurf wiederherzustellen**. Annehmen —
   weiterschreiben — speichern.

## Abmelden

Oben im CMS über Ihr Profil → „Sign out". An gemeinsam genutzten Computern
bitte immer abmelden.
